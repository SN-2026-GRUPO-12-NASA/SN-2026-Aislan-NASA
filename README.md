# NASA CMR Data Pipeline

Projeto desenvolvido para a atividade do 3º trimestre de Sistemas de Informação.

O projeto utiliza a API CMR (Common Metadata Repository), da NASA Earthdata, para coletar dados de coleções científicas.

## Arquitetura

NASA CMR → Python → Supabase → GitHub Pages

## API utilizada

Common Metadata Repository - CMR

Endpoint:
https://cmr.earthdata.nasa.gov/search/collections

## Tecnologias

- Python
- GitHub Actions
- PostgreSQL
- Supabase
- HTML, CSS e JavaScript
- GitHub Pages
